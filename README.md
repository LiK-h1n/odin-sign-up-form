# Odin: Sign-up Form

## Description

An elegantly designed sign-up page built with intermediate HTML and CSS. This project features a split-layout design, containing a graphical sidebar on one side and a comprehensive registration form on the other. It focuses heavily on semantic form structure, built-in HTML5 validation, and utilizing CSS pseudo-classes to provide dynamic visual feedback to the user.

## Skills Demonstrated

*   **HTML5 Forms & Validation:** Constructing structured forms with proper `<label>` and `<input>` pairings, and utilizing built-in validation rules (like required fields and correct data types) without relying on JavaScript.
*   **CSS Pseudo-classes:** Implementing dynamic states like `:focus` for active inputs and `:user-invalid` to instantly flag incorrect input (such as an invalid password) with a red border.
*   **Page Layout & Positioning:** Structuring a multi-column layout to cleanly separate visual assets from interactive content, and aligning form elements effectively.
*   **Asset & Typography Integration:** Incorporating custom external web fonts and high-resolution background images to create a professional user interface.
*   **Visual Hierarchy:** Utilizing semi-transparent background overlays to maintain text readability against busy background images, and applying subtle design details like box-shadows to improve the UI.
